# 策略共建台端到端体验 Review

**评审日期：** 2026-11-13  
**视角：** 首次体验产品的面试官 / 业务运营  
**环境：** 本机 Vite 演示页，桌面视口约 1648 × 882；全部为本地 mock，不连接线上服务。

## 走查路径

从“重置演示”回到策略基线，开启按肤质分组并保留宽适用范围；查看单题答案差异与引用抽屉；显式运行 8 条护肤样例，进入“防晒和粉底的先后顺序”回归详情；把分组范围收窄到“选购类”并重跑；随后进入跨场景向导，选择固定护肤模板、确认“家常菜 → 做法步骤 / 海参蒸蛋怎么做”，生成复用报告，打开家常菜答案来源抽屉并用 Escape 关闭。最后返回策略页修改一项设置，确认覆盖页保留旧运行快照并提示过期，再执行重置验证回到干净状态。

主链路结果符合预期：宽范围配置计算出 6 提升 / 1 持平 / 1 回归；收窄范围重跑后为 6 提升 / 2 持平 / 0 回归。引用来源、规则 trace、配置版本、planned 扩展和本地草稿边界均可见；重置会回到默认策略，清除覆盖结果，并让复用向导回到第一步。

## 发现的问题

### UX-01｜策略页把已有的匹配运行结果显示成“尚未运行”

**优先级：P2｜影响：中**  
**复现：** 运行样例并确认当前草稿与该次配置版本一致；从覆盖页返回“策略配置”。  
**实际：** 覆盖页仍有匹配当前草稿的最近一次运行结果，但策略页的摘要和“前往覆盖与回归”按钮仍显示“尚未运行固定样例检查 / 样例检查尚未运行”。  
**影响：** 用户可能重复运行，或误以为上次结果没有保存；这也削弱了跨页草稿与结果版本关联的可信度。  
**建议：** 根据 `coverageRun.configVersion` 与当前草稿指纹，统一展示“未运行 / 当前版本已检查 / 草稿已变更，结果过期”三态；点按钮时根据状态分别进入结果或提示重跑。

### UX-02｜页面间导航没有把主内容滚回顶部

**优先级：P2｜影响：中**  
**复现：** 在较长的覆盖详情或策略工作区下方，点击左侧主导航切换页面。  
**实际：** 新页面沿用旧页面的纵向滚动位置；标题、四步演示进度和页面导语可能被滚出视口，用户从页面中段开始。  
**影响：** 面试演示中容易让人以为页面缺内容或跳转不完整，也增加理解新页面上下文的成本。  
**建议：** 仅在跨页面导航时滚动到工作区顶部；同页页签切换则保留位置。用真实页面容器滚动，不要依赖整个窗口的偶然滚动状态。

### UX-03｜“选择来源模板”目前只有一个可选项

**优先级：P3｜影响：低**  
**复现：** 进入跨场景复用第一步。  
**实际：** 页面使用“选择一个明确版本”的文案，但只提供一个固定护肤示例模板。页面已说明这是固定演示模板，因此不会造成数据造假；不过用户仍可能预期有多个模板可比较。  
**建议：** 若暂不扩充数据，明确写为“使用唯一固定示例模板”；若要讲模板选择能力，再补充第二个可选模板及其差异，不要只增加空选择器。

### UX-04｜模板“版本”主要以技术指纹呈现

**优先级：P3｜影响：低**  
**实际：** `cfg-…` 指纹准确地区分配置快照，但首次使用者不容易知道它代表模板版本还是运行批次。  
**建议：** 同时显示人类可读的模板名与修订标签（如“护肤选购 · 演示基线 A”）；把 `cfg-…` 放在次级的“配置指纹”位置。明确区分模板版本与覆盖运行版本。

### UX-05｜结果过期时有两个相同的重跑主按钮

**优先级：P3｜影响：低**  
**复现：** 在已运行结果后修改策略，再进入覆盖页。  
**实际：** 过期提示条和“最近一次运行结果”标题区域同时显示“按当前草稿重跑 8 条”。两个按钮行为相同，视觉上都是主操作。  
**建议：** 保留过期提示条中的主按钮；结果标题处改为次级入口或移除，避免重复竞争注意力。

## 待复核观察

首次接入已打开的本地预览标签时曾出现白屏，刷新后页面正常挂载，之后主流程与重置均可重复操作。该现象可能是旧浏览器标签或 HMR 状态，不足以判定为产品缺陷；建议在正式面试前用全新标签冷启动一次。

本次主要在桌面视口走查，窄屏布局只做代码级检查，未逐一进行真实窄屏点击验证。样例集只有 8 条、复用目标只有 1 个，是当前概念原型的明确边界，不应据此推断线上覆盖率或通用复用能力。

## 评审结论

核心演示因果链清楚：**改策略 → 看单题变化 → 跑固定样例 → 定位并修复回归 → 复用到新场景**。未发现阻断主流程的硬错误。最建议优先处理 UX-01 和 UX-02：一个是状态文案与持久结果不一致，另一个会让页面切换后丢失阅读上下文。其余问题可作为面试 Demo 之后的产品化迭代项。
