# AI 搜答案策略共建台 · 概念 Demo

纯前端、本地 mock 的阶段性演示项目。阶段 0 工作台、阶段 1 数据与规则模拟引擎、阶段 2 策略编辑与答案溯源、阶段 3 固定样例覆盖与回归、阶段 4 跨场景复用向导均已实现。所有结果由本地规则引擎计算，不连接线上策略、真实模型或后端。

## 本地运行

首次安装锁文件中的依赖后运行：

```bash
npm ci
npm run dev
```

默认本地地址为 `http://127.0.0.1:5173/`。单元测试使用 `npm test`；严格 TypeScript 检查与生产构建使用 `npm run build`；预览构建使用 `npm run preview`。运行应用和规则模拟不需要真实模型、后端或在线业务服务；首次安装依赖需从 npm registry 获取开发包。

## 从头演示主线

1. 在“策略配置 → 答案呈现”中开启“按肤质分组”和“踩坑提醒”，保留默认的宽适用范围；右侧手机预览即时出现油皮/干皮分组和踩坑提醒（3 条引用），点开可看原文。
2. 进入“覆盖与回归”，显式运行 8 条独立标注样例。宽范围示例配置计算出 `6 提升 / 1 持平 / 1 回归`；选中“防晒和粉底的先后顺序”，查看缺失的“等待成膜”及触发规则。
3. 按回归详情建议把范围收窄为“选购类”，再显式重跑；当前固定样例结果为 `6 提升 / 2 持平 / 0 回归`。
4. 进入“跨场景复用”，确认固定的护肤来源模板和“家常菜 → 做法步骤 / 海参蒸蛋怎么做”目标，再生成复用报告。点击家常菜答案要点可检查其 mock 来源和规则 trace。

追问备用（P1）：在顶栏把身份切换为“商业化（示例）”，进入“护栏规则”提议把品牌说放在结论之前，查看冲突、规则负责人和待讨论选项，再“通知规则负责人并发起讨论”；草稿不会被改动。

策略、样例运行快照和复用向导状态跨页面保存在本地演示 store 中。修改策略后不会静默覆盖上次结果：覆盖页会比较配置指纹并提示重跑。顶部“重置演示”回到策略基线、清空运行和向导状态。

## 阶段 1：mock 数据与规则引擎

`src/data/` 包含场景与策略设置者元数据、existing/planned 组件目录、要点目录、27 条护肤和 15 条家常菜 mock 来源、8 条独立标注的护肤样例，以及护肤模板和家常菜复用目标。作者、组织、发布日期和互动数均为虚构演示数据。

`src/engine/` 提供五个纯函数：`resolveConfig` 合并配置并记录字段来源，`detectConflicts` 生成待讨论护栏事项但不自动采纳，`renderAnswer` 按来源条件和现有组件生成带 trace 的答案，`runCoverageCheck` 对照独立期望要点计算覆盖与引用指标，`reuseReport` 生成复用/改配置/planned 扩展清单并排除 planned 项的收益计数。

固定回归只说明本地固定 mock 上的规则模拟，不是线上实验或真实语义评测；样例期望与规则输出分开维护。

## 阶段 2：策略编辑、答案预览与溯源

策略工作区分为“内容依据 / 答案呈现 / 护栏规则”三个页签。可调整来源类型、亲身经验优先、时效窗口、正反面经验、商业内容标注、按肤质分组及适用范围、踩坑提醒、一句话结论和已有组件顺序。各设置项显示示例设置者、来源和适用范围；示例护栏只读并标负责人。控件变化立即重算“油皮夏天防晒怎么选”的本地答案，不会发布或影响线上策略。

手机预览可切换改动前/改动后，突出新增/移除要点；点击答案要点打开溯源抽屉，查看虚构原文、笔记/评论类型、作者类型、日期、立场、引用计数和命中的规则 trace。所有来源明确标为 mock；“可追溯、有依据”不代表平台为原帖真实性背书。

## 阶段 3：固定样例与回归修复

覆盖页首次进入不会伪造结果，用户显式运行 8 条护肤样例。页面展示配置版本、独立要点覆盖、引用可追溯率、陈旧引用、商业内容标注与逐样例差异。运行结果与本次配置快照绑定；草稿变更后保留旧结果并提示重跑。回归详情提供范围修复动作，修复后必须再次运行才能确认结果。

## 阶段 4：跨场景复用

复用向导按“选择来源模板 / 确认目标场景 / 查看复用报告”展开。来源为明确标注的护肤固定模板快照，目标为家常菜固定 mock；报告按“直接复用 / 改配置 / 待研发扩展点”分栏，复用占比由引擎计算，planned 项不计入收益。家常菜答案仅使用标记为 existing 的组件，点击要点可继续查来源。

## 体验走查

完整主线已在本机桌面预览中实际操作；问题、复现步骤、影响与建议见 [`docs/ux-review.md`](./docs/ux-review.md)。优先跟进项是策略页对已运行检查状态的提示，以及页面导航后的滚动位置。

## 边界

业务只可调整已定义策略位；召回、排序、模型、新数据源和新答案组件不在此配置。项目不宣称真实模型表现、语义准确率、线上收益或真实权限系统。实现与走查待办见 [`TODO.md`](./TODO.md)。
